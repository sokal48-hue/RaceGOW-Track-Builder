# Feedback and contributions

Thanks for helping improve RaceGOW Track Designer!

## Report a bug

Open an Issue with:

1. A short description of what went wrong.
2. Browser/OS and the version shown in the app header (V70).
3. Steps to reproduce the issue.
4. A screenshot or an **exported JSON track** if it helps demonstrate the problem (check that it contains nothing private before attaching).
5. What you expected to happen.

## Request a feature

Explain the intended racing/building workflow, what controls or output you want, and how the change would help racers or track builders.

## Source code contributions

Please discuss significant changes in an Issue first. **Source code licensing and contribution permissions have not yet been finalized**; coordinate with the repository owner before submitting source-code modifications.
