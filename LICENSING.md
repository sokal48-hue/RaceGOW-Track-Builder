# Licensing decision needed

**This release package deliberately does not include a `LICENSE` file.** The application owner has not specified an open-source license, and it would be inappropriate to choose one on their behalf.

A publicly visible GitHub repository allows people to view and fork the repository through GitHub's platform features, but **does not automatically grant broad permission to modify, redistribute, or republish the code**.

The project description invites the RaceGOW team and community to use and share the application. To make those permissions unambiguous, the author should add an explicit license or permission statement before announcing unrestricted reuse.

Options to consider:

- **MIT license** — broad permission to use, modify, and redistribute, with attribution and warranty disclaimer. A common choice if unrestricted reuse is intended.
- **Apache License 2.0** — permissive like MIT, with additional patent terms.
- **Custom community-use license/permission** — may specify limits, but requires careful drafting and is typically not considered an open-source license.

Choose one intentionally, then add the corresponding `LICENSE` file and update the README. For licensing guidance see https://choosealicense.com/ .
