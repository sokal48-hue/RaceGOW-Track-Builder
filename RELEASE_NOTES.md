# 🏁 RaceGOW Track Designer V71 — Release Notes

**Status:** Public Track Designer release  
**Online app:** [Launch Track Designer](Designer.html)  
**Standalone download:** [Designer.html](Designer.html)  
**Website:** https://sokal48-hue.github.io/RaceGOW-Track-Builder/

## What's new in V71

- **Clearer printable instructions:** Two assembly steps per row, flowing onto further pages, with focused/zoomed highlights and labeled part icons, names, and quantities.
- **Floor-footprint controls:** Assign Required or Optional status while placing links, including Auto mode. Bulk add/remove protects existing required floor links.
- **Right-click link menu:** Convenient contextual actions for selecting endpoints, editing eligible floor-link classification, and removing links.
- **Master Reset:** Clear the track and start over without reloading, including when a locked track has been imported.
- **Artwork correction:** Restored complete RaceGOW branding imagery in the application.

## Distribution update (same application version)

The public GitHub Pages application now uses the stable filename **`Designer.html`**. This replaces version-specific filenames in website links and allows later updates without changing `index.html`. The internal application version remains **V71**.

A companion Flight Path Designer prototype is available at **[`Route.html`](Route.html)** (V28). It is under active development and is not part of this Track Designer release.

## Using the app

Open the website to launch the designer, or download `Designer.html` and open it in a modern browser for offline use. Export your tracks as JSON and use the built-in print feature for assembly instructions.

## Notes and feedback

Browser interaction and printed-output checks should be performed for each published build. Protected JSON layouts restrict edits through the app interface; they are not tamper-proof. The RaceGOW team and community can submit feedback using GitHub Issues or reach **RaceGOW #569** on Discord.
