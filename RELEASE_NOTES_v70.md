# RaceGOW Track Designer V70 — Release 1.0

**Initial public release of the standalone RaceGOW 3D track-building application.**

## Highlights

- Interactive 6 × 6 × 6 track-construction workspace with rotation, zoom, and visual editing.
- Presets for cubes, square gates, and START/FINISH configurations.
- Automatic joint classification and live link/connector inventory.
- Optional floor footprint links and half-grid support placement.
- JSON-based track import/export, including app-level protected track layouts.
- Printable multi-angle build guides, progressive assembly illustrations, and material summaries.
- One self-contained HTML file; no dependencies or installation required.

## How to run

Download `RaceGOW_Track_Designer_v70.html` and open it in a modern browser. Export a JSON file to share a designed course; import a JSON file to reopen one.

## Scope

V70 covers **physical track design and assembly planning**. Automated lap direction and flight-route creation are being developed in a separate companion app and are not in V70.

- Locked-track exports restrict edits in the app interface, but are not a secure access-control mechanism.
- Inspect real-world stability and clearances before assembly/use.
